# PodFlow Pro (路線 B - 深度學習多模態 AI 導播與防破圖 CFR 渲染引擎)

本手冊說明【路線 B】架構之完整執行方式、AI 多模態決策大腦原理，以及徹底根治「影片破圖、綠屏、拉絲」的 CFR 全關鍵影格預標準化技術。

---

## 🌟 路線 B 兩大核心技術突破

### 1. 【AI 決策大腦】深度聲學頻譜 ＋ 視覺嘴唇神經多模態發言辨識 (Active Speaker Detection)
* **人聲共振峰頻段神經分析 (Spectral Formant Band 300Hz ~ 3400Hz)**：
  透過短時傅立葉變換與頻譜通量分析，精準鎖定人類說話時特有的共振峰能量分佈，有效剔除敲擊桌面、咳嗽、笑聲爆音與環境冷氣雜音。
* **人臉嘴唇開合動態追蹤 (Visual Lip Motion)**：
  調用視覺分析即時偵測講者嘴唇幾何形狀變化率，並扣除整體頭部晃動/點頭干擾。
* **跨模態置信度融合**：
  $$\text{Confidence}(t) = \text{AudioSpectralScore}(t) \times (0.30 + 0.70 \times \text{LipMotion}(t))$$
  **徹底根除麥克風串音 (Mic Bleed)**：當一人大聲說話導致另一人麥克風收音時，若另一人嘴巴靜止，視覺權重會直接壓制該聲軌置信度，絕不誤切鏡頭！

---

### 2. 【防破圖渲染管線】CFR 全關鍵影格預標準化 (Anti-Tearing CFR Intra Pipeline)
* **破圖原因根治**：
  傳統 Concat Demuxer 在切割 iPhone 影片時破圖，主因是 iPhone 為**動態可變幀率 (VFR)** 且採用長 GOP（每 1~2 秒才有一張 I-frame 關鍵影格）。當切入點落在 P/B-frame 上時，解碼器因缺少前導影格而產生嚴重的馬賽克破圖、拉絲或綠屏。
* **路線 B 解決方案**：
  在剪輯拼接前，系統自動將相機素材預先進行 **CFR 30fps ＋ All-Intra (`-g 1`) 標準化處理**，確保**每一張影格皆為獨立完整的關鍵影格**，且色彩空間統一鎖定為廣播級 Rec.709。
* **結果**：在進行多達數百次鏡頭毫秒切換時，解碼器能 100% 毫秒精準解碼，**完全零撕裂、零綠屏、零破圖！**
